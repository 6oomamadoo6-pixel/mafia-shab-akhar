# مافیا | شب آخر

بازی اندرویدی فارسی، عمودی و کاملاً آفلاین؛ یک بازیکن انسانی در برابر ۹ بات.

## الهام از تجربه مافیامون (بدون کپی)
بر اساس قابلیت‌هایی که در معرفی‌ها و اطلاعیه‌های عمومی مافیامون منتشر شده‌اند، این پروژه از ایده‌های زیر الهام می‌گیرد و آن‌ها را برای تجربه آفلاین بازطراحی می‌کند:
- مسابقه دوستانه و امتیازی و لابی‌های سطح‌بندی‌شده → حالت‌های تمرینی و رتبه محلی
- آواتار، قاب، تاج و بسته‌های ظاهری → فروشگاه نمایشی و پروفایل قابل تنظیم
- گروه و تعامل بازیکنان → فهرست دوستان/بات‌های موردعلاقه
- تاریخچه و جزئیات مسابقه → ذخیره تاریخچه روی دستگاه
- راوی قابل تنظیم → روایت متنی و پشتیبانی آزمایشی از گفتار دستگاه
- تماشای مسابقه → در آینده بازپخش محلی بازی‌های بات‌ها
- لایک/دیسلایک لابی → واکنش‌های محلی در نسخه‌های بعد

## گیم‌پلی فعلی
- ۱۰ نفر: کاربر + ۹ بات
- ۳ مافیا، ۱ دکتر، ۱ کارآگاه و ۵ شهروند
- شب معارفه بدون قتل، روز معارفه، شب عملیات، بحث روز، اتهام و رأی
- رأی مساوی به مرحله دفاعیه/رأی نهایی می‌رود؛ در صورت تساوی دوباره شب آغاز می‌شود.
- بات‌ها شخصیت‌های گفتاری متفاوت و اقدام‌های شبانه دارند.
- نتیجه و تاریخچه مسابقات به‌صورت محلی روی دستگاه ذخیره می‌شود.
- بدون حساب کاربری، سرور، اینترنت یا بازی با انسان‌های دیگر.

## تصویر رابط کاربری
صفحه اصلی و صفحات داخلی از فایل `app/src/main/assets/lobby-reference.jpg` استفاده می‌کنند. این فایل باید همان تصویر مرجع لابی باشد تا نوشته‌ها و تایپوگرافی داخل تصویر عیناً حفظ شوند. دکمه‌های شفاف روی نواحی قابل لمس قرار گرفته‌اند.

## ساخت APK
با Push به شاخه main یا اجرای دستی workflow با نام **Build Android APK**، فایل APK ساخته می‌شود.
از مسیر Actions → آخرین اجرای موفق → Artifacts فایل `mafia-shab-akhar-debug-apk` را دانلود کن.

## نکته توسعه
نسخه فعلی یک نمونه آفلاین در حال توسعه است. هوش بات‌ها در این نسخه الگوریتمی و قانون‌محور است و هنوز مدل زبانی واقعی یا همه قوانین حرفه‌ای سناریوهای گوناگون پیاده نشده‌اند.
