# مافیا | شب آخر

پروژه بازی اندروید فارسی با رابط عمودی و تم شبانه.

## وضعیت توسعه

- رابط اندروید WebView و صفحه لابی.
- صف آنلاین با ظرفیت ۱۰ بازیکن واقعی از طریق Socket.IO.
- نمایش ۱۰ جایگاه و تعداد افراد حاضر در صف.
- مسابقه فقط پس از تکمیل ۱۰ جایگاه شروع می‌شود؛ بازیکن بات به صف آنلاین اضافه نمی‌شود.
- حالت تمرینی آفلاین با بات‌ها جداست.
- سرور آزمایشی Node.js در پوشه `server/`.
- نقش‌های اولیه سرور: ۳ مافیا، دکتر، کارآگاه و ۵ شهروند.

## راه‌اندازی سرور آزمایشی

1. وارد Render شو و از New یک Blueprint بساز.
2. مخزن `6oomamadoo6-pixel/mafia-shab-akhar` را متصل کن.
3. Render فایل `render.yaml` را تشخیص می‌دهد؛ سرویس `mafia-shab-akhar-server` را Deploy کن.
4. پس از Deploy، آدرس HTTPS سرویس را کپی کن.
5. در اپ، تنظیمات را باز کن و آدرس سرور را ذخیره کن.
6. برای تست چندنفره، APK را روی چند گوشی نصب کن و همه را به صف عمومی وصل کن.

آدرس سرور باید به شکل `https://....onrender.com` باشد. مسیر ریشه باید JSON با وضعیت online و مسیر `/health` پاسخ سالم بدهد.

## محدودیت‌های فعلی (مهم)

این یک زیرساخت آزمایشی اولیه است، نه نسخه نهایی آنلاین:
- سرویس رایگان Render پس از ۱۵ دقیقه بدون ترافیک ورودی/پیام WebSocket می‌خوابد و بیدار شدن مجدد ممکن است حدود یک دقیقه طول بکشد.
- وضعیت صف و مسابقه فعلاً در حافظه سرور است؛ با restart یا deploy پاک می‌شود.
- در این مرحله صف ۱۰ نفره، اتصال بلادرنگ، شروع مسابقه و نمایش نقش اولیه پیاده شده؛ موتور کامل مراحل شب، صحبت نوبتی، رأی‌گیری، دفاعیه، ذخیره تاریخچه و ضدتقلب هنوز باید تکمیل شود.
- برای استفاده عمومی و همیشه‌روشن، سرور پایدار همراه دیتابیس و سرویس میزبانی بدون خواب لازم است.

## ساخت APK

با هر Push به شاخه main یا اجرای دستی workflow با نام **Build Android APK**، فایل APK ساخته می‌شود.
از مسیر Actions → آخرین اجرای موفق → Artifacts فایل `mafia-shab-akhar-debug-apk` را دانلود کن.
