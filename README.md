# YAFTA | یافتا

اپلیکیشن آزمایشی نیازمندی‌ها و آگهی‌های محلی برای بازار ایران.

این مخزن از پروژه آزمایشی «مافیا | شب آخر» به **YAFTA** تغییر داده شده است.

## امکانات نسخه نمایشی
- رابط فارسی و راست‌چین با پس‌زمینه آبی روشن
- جست‌وجوی آگهی‌ها و دسته‌بندی‌ها
- آگهی‌های نمونه و صفحه جزئیات
- نشان‌کردن آگهی‌ها
- فرم ثبت آگهی آزمایشی و انتخاب شهر
- ذخیره محلی آگهی‌ها و علاقه‌مندی‌ها در WebView

## رنگ‌های برند
- پس‌زمینه: #EAF3FC
- کارت‌ها: #FFFFFF
- رنگ اصلی: #3278C8
- سطوح فرعی: #DCEBFA

## ساخت اندروید
پروژه با Android Gradle Plugin و WebView محلی ساخته شده است. پوشه پروژه را در Android Studio یا محیط سازگار با Gradle باز کرده و Build بگیرید.

## محدودیت‌های نسخه فعلی
این نسخه نمونه اولیه رابط و جریان‌های اصلی است. آگهی‌ها، جست‌وجو و علاقه‌مندی‌ها فعلاً روی همان دستگاه ذخیره می‌شوند. ورود واقعی کاربران، پایگاه داده و API مرکزی، آپلود تصویر، پیام‌رسانی، پنل مدیریت و نسخه‌های وب و iOS هنوز پیاده‌سازی نشده‌اند.
