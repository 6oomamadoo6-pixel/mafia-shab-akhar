# مافیا | شب آخر

نسخه آزمایشی اندروید با رابط فارسی عمودی.

## وضعیت فعلی
- بازی تک‌نفره با ۹ بات (در مجموع ۱۰ بازیکن)
- ترکیب نقش‌ها: ۳ مافیا و ۷ شهروند
- نقش‌های ویژه: دکتر و کارآگاه
- رابط راست‌چین فارسی با تم شبانه، طلایی و قرمز
- اجرای بازی بدون نیاز به اینترنت

این نسخه نمونه اولیه قابل تست است؛ رفتار بات‌ها و قوانین بازی هنوز در حال توسعه‌اند و هوش مصنوعی ابری یا بازی آنلاین چندنفره ندارد.

## ساخت APK
با هر Push به شاخه main یا اجرای دستی workflow با نام **Build Android APK**، فایل APK ساخته می‌شود.
از مسیر Actions → آخرین اجرای موفق → Artifacts فایل `mafia-shab-akhar-debug-apk` را دانلود کنید.
